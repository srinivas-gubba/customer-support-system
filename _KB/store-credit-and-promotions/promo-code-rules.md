# Promo Code Rules

**Summary.** **One promo code per order.** Codes apply at checkout, **cannot be applied
retroactively** by default, and can't be used to buy gift cards. If a returned item drops the order
below a promo threshold, the discount is **prorated**.

## Rule details
- **One code per order**; codes don't stack.
- Apply at checkout only; **no retroactive** application by default (discretionary goodwill exception
  — escalate if outside authority).
- Promo codes can't purchase **gift cards** ([PROMO-004](gift-cards.md)).
- **Proration:** if a return brings the order below the promo's minimum, the discount is recalculated
  and deducted from the refund ([REF-005](../refunds/partial-refunds-and-deductions.md)).
- Why a code fails: expired, minimum not met, excluded items, one-per-customer used, typo.

## Examples
1. Two codes offered → apply the one that saves the most; only one allowed.
2. "$10 off over $50" used, customer returns an item leaving $45 → discount prorated/removed from
   the refund.
3. "Forgot to apply my code" → may apply retroactively if valid/eligible; escalate if beyond
   authority.

## What the agent must not do
- Do not stack multiple codes.
- Do not reveal unpublished/internal codes.

## Escalation
Retroactive application beyond authority, or disputes → escalate.

## Customer-facing wording
> "We allow one promo code per order. Let's check why it's not applying — is the order above the
> minimum and are the items eligible? Share the code and I'll take a look."
