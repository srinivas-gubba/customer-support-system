# How to Start a Return

**Summary.** Start a return in the returns portal at **{{RETURNS_PORTAL_URL}}** with the order number
and email, pick the item(s) and a reason, choose **refund or exchange**, and get a prepaid or
customer-paid label depending on fault. The customer has **30 days from starting the return** to drop
it off.

## Steps
1. Go to {{RETURNS_PORTAL_URL}} (or **Order history** if signed in).
2. Enter the **order number** and the email used at checkout.
3. Select the item(s) and a **reason** — the reason sets who pays shipping (fault vs. change of mind,
   [RET-005](return-shipping-costs.md)).
4. Choose **refund** ([REF-001](../refunds/refund-eligibility-and-window.md)) or **exchange** ([RET-006](exchanges.md)).
5. Print the label / get drop-off instructions (carrier drop-off or in-store where available).
6. Pack in original packaging with all parts; attach the label.
7. Drop off and keep the receipt/tracking. Refund is processed after receipt + inspection → timing
   in [REF-004](../refunds/refund-timing-by-payment-method.md).

## Rule details
- The agent can **initiate the return** for the customer — collect order ID, email, item, reason,
  and chosen outcome.
- Drop-off deadline: **30 days** after the return is started.

## Examples
1. Change of mind on a $40 shirt → start return, customer-paid label, refund on receipt.
2. Wrong item received → start return with reason "wrong item"; prepaid label; see
   [DMG-002](../damaged-or-wrong-items/wrong-item-received.md).

## What the agent must not do
- Do not set the reason as "change of mind" when the store is at fault (that would wrongly charge the
  customer for return shipping).

## Escalation
Portal failures the agent can't work around, or value over $100 → escalate.

## Customer-facing wording
> "I can start that return now. For order #{id}, which item(s), and would you like a refund or an
> exchange? I'll send the label straight to your email."
