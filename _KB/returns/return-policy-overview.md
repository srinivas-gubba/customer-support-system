# Return Policy Overview: 30 Days, Original Condition

**Summary.** {{STORE_NAME}} accepts most items for return within **30 calendar days of delivery** in
**original, unused condition** with packaging and tags. The customer may choose a **refund to the
original payment method** or an **exchange**. Change-of-mind return shipping is the customer's cost;
the store pays when the store is at fault.

## Rule details
- **Window:** 30 calendar days from the delivery date (same clock as refunds, [REF-001](../refunds/refund-eligibility-and-window.md)).
- **Condition:** new/unused, original packaging, all tags/accessories → see [RET-003](return-condition-requirements.md).
- **Outcome:** refund (REF-001) or exchange ([RET-006](exchanges.md)).
- **Return shipping:** customer pays for change of mind; free when store at fault → [RET-005](return-shipping-costs.md).
- **Exclusions:** the published non-returnable list → [RET-002](non-returnable-items.md).
- This policy is conspicuously posted (required by CA Civil Code § 1723 when a store limits refunds);
  see [LEGAL-001](../legal/compliance-notes.md).

## Examples
1. Unworn shirt, delivered 10 days ago, change of mind → eligible; customer pays return shipping;
   refund $ item price.
2. Opened groceries → **not returnable** (RET-002) unless damaged/spoiled on arrival.
3. Item delivered 45 days ago → outside window → [REF-006](../refunds/refunds-outside-window-decline.md).

## What the agent must not do
- Do not accept returns of non-returnable items for change of mind.
- Do not promise free return shipping for a change-of-mind return.

## Escalation
Order value over $100, out-of-window exception requests, or disputed eligibility → escalate.

## Customer-facing wording
> "You can return most items within 30 days of delivery, unused and in original packaging, for a
> refund or exchange. Want me to start a return for order #{id}?"
