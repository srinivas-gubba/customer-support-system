# Return Condition Requirements

**Summary.** To be returned for change of mind, an item must be **new/unused, in original packaging,
with all tags, accessories, manuals, and parts**. Electronics must be **factory reset with accounts
removed**. Items returned incomplete or used may receive a **reduced (partial) refund** or be
refused.

## Rule details
- Required: unused/unworn, original packaging, tags attached, all included accessories/parts.
- Furniture must be returned **unassembled** → see [PROD-004](../product-specific-rules/furniture-and-bulky-items.md).
- Electronics must be **wiped / factory reset** and signed out of all accounts → see
  [PROD-003](../product-specific-rules/electronics-data-wipe-and-returns.md).
- IF returned with missing parts or used condition → **partial refund** or refusal → see
  [REF-005](../refunds/partial-refunds-and-deductions.md).

## Exceptions
- Store-at-fault returns (damaged/defective/wrong) are **not** held to "unused" condition — the
  defect is the point. Route to [DMG-001](../damaged-or-wrong-items/damaged-item-claims.md).

## Examples
1. Unworn shoes in the original box with tags → full refund.
2. Shoes worn outside, scuffed soles, change of mind → may be **refused** or partially refunded.
3. Laptop returned still logged into an account → ask the customer to factory reset first (PROD-003).

## What the agent must not do
- Do not approve a full refund on a clearly used/incomplete change-of-mind return — flag for partial
  or refusal.
- Do not apply condition rules against a legitimate damaged/defective claim.

## Escalation
Disputed condition, high-value incomplete returns, or value over $100 → escalate.

## Customer-facing wording
> "To return it for a refund, it needs to be unused with the original packaging and tags. For
> electronics, please factory-reset and sign out first so your data is safe."
